# NpStructure

The non-proportional Structure screen: the programme strip (the terms Universe keeps in the NP Treaty Detail right pane) above the `LayerTable`.

**Consumer provides:** the contract, the treaty type (sets RISK / CAT / BOTH), `programme`, `layers`, `onSave`.

- Programme strip: Deductible (layer-1 attachment), Type of XL, Accounting Method, Accounts, Est. GNPI (default EGNPI for new layers), Brokerage %, Taxes %, No Claims Bonus %, Profit Commission %.
- Changing Deductible re-cascades every attachment.
- Stop Loss swaps the table for Attach LR % / Limit LR % / EPI per layer; Aggregate XL for Aggregate Limit / Aggregate Deductible / Deductible / AAD / Risk / Cat.
