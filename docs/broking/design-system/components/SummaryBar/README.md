# SummaryBar

The strip under the header pill on every capture screen: the contract's key facts in one line, its UMR and UUID chips, and the Triangulations available toggle on proportional screens.

**Consumer provides:** cedant, country, broker, currency, treaty type and COB names; `umr`; `contractId`; `status`; optional `parentUmr` for renewals.

- Facts are separated by `·` and shown as "—" until captured.
- The UMR chip is the only place the UMR is shown after creation; clicking it copies it.
- A renewal shows an `info` badge "Renewal of B0621DAR25TR004".
