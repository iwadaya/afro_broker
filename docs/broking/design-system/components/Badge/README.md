# Badge

Status words in a pill with a leading dot. One per contract status, plus pane tags.

| Status | Variant |
| --- | --- |
| DRAFT | neutral |
| SUBMITTED, QUOTED | `info` |
| FIRM ORDER | `warn` |
| BOUND, SIGNED | `success` |
| NTU, CANCELLED | `danger` |

**Consumer provides:** `status` or `variant` + label. The word always carries the meaning; colour only reinforces it.
