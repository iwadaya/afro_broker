# Pane

The Universe `card glass`: a titled pane with a head (UPPERCASE title, optional tag or toggle on the right) and a body of FormRows grouped by `mini` section titles.

**Consumer provides:** `title`, `tag` or `headRight` (a TogglePill), children.

- Proportional Treaty Detail is four Panes in a 2-column grid (`ab-grid-2`, `space-5` gap). NP Contract Details is one Pane.
- Section titles inside a pane use `section-title` (EPI, BROKERAGE & TAXES, SLIDING SCALE).
- Don't nest panes or put a pane inside a table.
